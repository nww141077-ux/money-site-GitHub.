# Сайт для заработка (донаты + Дзен)

## Запуск на своём ПК
1. Установи Node.js LTS с https://nodejs.org (далее — далее — готово).
2. Распакуй архив в любую папку.
3. Открой папку в терминале и выполни:
   npm install
   npm start
4. Открой в браузере http://localhost:3000

## Настрой под себя
1. Открой public/config.json и впиши свои ссылки:
   - boostyUrl — страница на Boosty (донаты + подписки)
   - dzenUrl — ссылка на твой канал в Дзене
   - metrikaId — номер счётчика Яндекс Метрики
2. Статьи добавляй в public/data/articles.json (копируй блок по образцу).

## Яндекс Метрика
Зарегистрируйся на metrika.yandex.ru, создай счётчик, получи код
и вставь его перед </head> в index.html и article.html.
Затем настрой цели: клик по кнопке доната (событие «клик по ссылке»)
и переход на канал Дзена.

## Переход из «на ПК» в публичный интернет
Для заработка сайт должны видеть другие. Варианты:
- Бесплатно: загрузи папку public на GitHub Pages или Netlify
  (донаты работают, так как кнопки ведут на внешние сервисы).
- Своё: VPS от ~200–300 ₽/мес (Timeweb, reg.ru) + домен .ru ~200–700 ₽/год.
  Заливаешь проект, npm install && npm start, ставишь nginx или просто
  порт 3000 + Cloudflare.
